# vatSys VATPRC 插件

VATPRC 官方 vatSys 插件的**下载与需求反馈入口**。插件源代码私有维护，本仓库不包含代码。

## 下载

前往 [Releases](../../releases) 页面下载最新版本，按压缩包内说明安装。

## 反馈问题 / 提出需求

请通过 [Issues](../../issues) 提交，选择对应模板：

- **Bug 报告**：插件功能异常、崩溃、与预期不符，或因插件缺失某能力导致管制信息出错。
- **功能请求**：希望插件新增或改进的功能。

### 功能请求的处理流程

1. 提交后 issue 自动标记为 `S-待运行部确认`；
2. 运行部会在 issue 内确认需求是否成立，确认后标记为 `S-运行部已批准`；
3. 已批准的需求进入开发排期。**确认前不会排期，请耐心等待。**
