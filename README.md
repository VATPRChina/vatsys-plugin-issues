# vatSys VATPRC 插件

VATPRC 官方 vatSys 插件的**下载与需求反馈入口**。插件源代码私有维护，本仓库不包含代码。

## 下载

前往 [Releases](../../releases) 页面下载最新版本，按压缩包内说明安装。

> [!IMPORTANT]
> 本插件随VATPRC官方vatSys发布，大部分情况下用户不应自行从本仓库下载最新版

> [!CAUTION]
> 本插件版本按[Semver规范](https://semver.org/lang/zh-CN/)命名，若用户急需部分功能，可从本仓库下载未随扇区发布的测试版（-alpha, -beta, -pre-release, -build）

## 参与贡献

本插件因分部需要暂未开源，请参考[VATPRC技术贡献规范](https://www.vatprc.net/zh-cn/docs/policy/tech-contribution)申请参与开发

## 反馈问题 / 提出需求

请通过 [Issues](../../issues) 提交，选择对应模板：

- **Bug 报告**：插件功能异常、崩溃、与预期不符，或因插件缺失某能力导致管制信息出错。
- **功能请求**：希望插件新增或改进的功能。

### 功能请求的处理流程

1. 提交后 issue 自动标记为 `S-待运行部确认`；
2. 运行部会在 issue 内确认需求是否成立，确认后标记为 `S-运行部已批准`；
3. 已批准的需求进入开发排期。**确认前不会排期，请耐心等待。**
